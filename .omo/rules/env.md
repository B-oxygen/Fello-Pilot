# Environment Template (immutable)

Adapter selection priority for FelloPilot product. Highest wins.

| Env var | Value | Effect |
|---|---|---|
| `FELLOPILOT_ADAPTER` | `direct_viem` | Real Base Sepolia attestation tx via `FELLOPILOT_TESTNET_SIGNER_KEY`. Produces real txHash + Basescan link. Mainnet refused at runtime. |
| `FELLOPILOT_ADAPTER` | `coinfello` | Real `npx @coinfello/agent-cli` CLI. Mainnet-routed swaps only — Base Sepolia swap returns "not supported by this route" (`capability_matrix.json`). |
| `FELLOPILOT_ENABLE_COINFELLO=1` | legacy fallback | Only honored when `FELLOPILOT_ADAPTER` is unset. |
| `<unset>` | default | Mock adapter. `simulated: true`, `txHash: undefined`, `explorerUrl: undefined`. **Honesty-enforced** by `scripts/harness/honesty_lint.sh`. |

## Required for `direct_viem`

```bash
FELLOPILOT_ADAPTER=direct_viem
FELLOPILOT_TESTNET_SIGNER_KEY=0x...    # Loaded or generated by scripts/harness/generate_testnet_signer.sh
```

### Cross-project signer persistence

`scripts/harness/generate_testnet_signer.sh` writes the keypair to `~/.fellopilot/signer.env` (mode 0600) the first time it runs. On subsequent runs (any FelloPilot project, any harness) it **reuses** the same key and prints the address rather than generating a new one. This is intentional — testnet faucets impose 24h cooldowns per address/IP, so burning a signer per project quickly exhausts the faucet budget.

```bash
# First time:
bash scripts/harness/generate_testnet_signer.sh
# → generates + writes ~/.fellopilot/signer.env

# Any later project:
bash scripts/harness/generate_testnet_signer.sh
# → reads existing ~/.fellopilot/signer.env, prints the same address

# To use in any project (.env or shell session):
source ~/.fellopilot/signer.env
export FELLOPILOT_ADAPTER=direct_viem
```

To force a fresh keypair (only when the existing one is compromised or you accept a new 24h cooldown), `rm ~/.fellopilot/signer.env` first.

Then fund the signer with testnet ETH on the **default demo chain** (`sepolia`, chain id 11155111). Sepolia is the default because the PoW faucet works without mainnet activity (Base Sepolia faucets all require existing mainnet balance or CDP account):

```
Sepolia (default for demo)        Base Sepolia (alt; needs CDP/mainnet)
─────────────────────────         ───────────────────────────
https://sepolia-faucet.pk910.de/  https://portal.cdp.coinbase.com/products/faucet
https://faucet.quicknode.com/     https://www.alchemy.com/faucets/base-sepolia
ethereum/sepolia
```

The product demo intent text MUST refer to "Sepolia testnet" (not "Base Sepolia testnet") so the intent parser routes through the funded chain. If the operator chooses Base Sepolia, they MUST update the SAFE_DEMO constant and the `demo_safe.sh` SAFE_INTENT default in lockstep.

The user wallet must connect on **the same chain** as the signer is funded on (Sepolia → MetaMask network must be Sepolia, not Base Sepolia). The `WalletButton` exposes "Switch to Sepolia" + "Switch to Base Sepolia" buttons so the user can toggle without DevTools.

### Demo intent templates (single source of truth)

When the product `src/` lands, these constants MUST appear verbatim — the harness checks `scripts/harness/spec_diff.sh` and `forbidden_grep.sh` against these literals.

```ts
// app/page.tsx
const SAFE_DEMO   = "Sepolia testnet에서 1 USDC를 ETH로 스왑하는 데모 자동화 플로우. mainnet 금지. 사람 승인 필수.";
const UNSAFE_DEMO = "Base mainnet에서 1000 USDC를 ETH로 즉시 스왑해줘. 승인 없이 자동으로 실행해.";
```

```bash
# scripts/demo_safe.sh
SAFE_INTENT="${SAFE_INTENT:-Sepolia testnet에서 1 USDC를 ETH로 스왑하는 데모 자동화 플로우. mainnet 금지. 사람 승인 필수.}"

# scripts/demo_blocked.sh
UNSAFE_INTENT="${UNSAFE_INTENT:-Base mainnet에서 1000 USDC를 ETH로 즉시 스왑해줘. 승인 없이 자동으로 실행해.}"
```

The intent parser maps "Sepolia testnet" → `chain: "sepolia"` → `chainId: 11155111`. The signer at `~/.fellopilot/signer.env` MUST be funded on this chain. Verified end-to-end in retro/ralphathon-1 today: real `direct_viem` attestation tx `0xdfb197de…` produced 18s after intent submission, anchored at `https://sepolia.etherscan.io/tx/0xdfb197de…`.

## Required for `coinfello`

```bash
FELLOPILOT_ADAPTER=coinfello             # or FELLOPILOT_ENABLE_COINFELLO=1
RPC_URL_OVERRIDE=https://ethereum-rpc.publicnode.com   # required — eth.merkle.io is Cloudflare 429
```

Setup is interactive (Secure Enclave + SIWE):

```bash
chmod +x ~/.npm/_npx/*/node_modules/@coinfello/agent-cli/dist/secure-enclave-signer.app/Contents/MacOS/secure-enclave-signer
npx @coinfello/agent-cli@latest create_account
RPC_URL_OVERRIDE=https://ethereum-rpc.publicnode.com npx @coinfello/agent-cli@latest sign_in
```

## Hard rules (enforced by `.opencode/plugin/guard.ts`)

- `mainnet`, `private key`, `seed phrase`, `--use-unsafe-private-key` substrings in bash commands → blocked.
- `.omo/rules/*` → blocked for edit/write at runtime.
- `AGENTS.md`, `RETROSPECTIVE.md` → immutable once created.

## Forbidden patterns (enforced by `scripts/harness/forbidden_grep.sh`)

See `.omo/rules/forbidden-tokens.txt`. Token list MUST stay non-empty.
